# 🤝 TeamSphere Pro: 戦略的チーム最適化エンジン

TeamSphere Proは、大規模なエンジニアコミュニティの中から、プロジェクトの目的に応じて最適なチームをAIが選抜・分析するプラットフォームです。

## 🌟 プロジェクトの概要
本プロジェクトでは、**Stack Overflow Annual Developer Survey 2022** のデータを活用し、849名のエンジニアのスキルセットをネットワーク解析と機械学習でモデル化しています。

### 1. コミュニティ検出によるチーム編成
単なるスキルの有無だけでなく、エンジニア同士の「スキルの近接性」をグラフ理論に基づき解析しています。
- **グラフ構造の構築**: 共起するスキル（言語）をエッジとして接続。
- **Louvain法によるコミュニティ検出**: 互いに補完し合う、または専門性が近いエンジニアを自動的にグループ化。
- **現実的な運用**: 今回は技術スタックを扱っていますが、現実の組織運用では「趣味」「価値観」「過去の協業経験」などをデータ化することで、**「気が合う（ソフトスキル面でも相性が良い）コミュニティ」**を特定し、そこから最適なチームを編成することが可能です。

### 2. 機械学習 (Machine Learning) の役割
本アプリでは、以下の機械学習パイプラインを実装しています。
- **Multi-label Binarizer**: 多様なスキルスタック（多ラベルデータ）を数値ベクトルへ変換。
- **Random Forest Classifier**: 過去の膨大な職種データを学習したモデルにより、現在のスキルセットからそのエンジニアが果たすべき「実質的な役割（AI Role）」を予測します。
- **戦略的スコアリング**: ユーザーが選択した5つの重点カテゴリ（Data Science, Cloud, Web等）に基づき、各候補者の適合度をリアルタイムで算出します。

## 🛠 機能の特徴
- **全体コミュニティ構造の可視化**: 849名のつながりを「スキルの銀河」として俯瞰。
- **5要素の戦略選択**: 重視するスキルをチェックボックスで選択。全選択時は「バランス型」、特定選択時は「特化型」チームを自動編成。
- **チーム分析（レーダーチャート）**: 編成された5人の合計戦闘力を5つの軸で可視化。
- **役職割り当て**: ネットワーク内の「中心性（ハブ度）」に基づき、リーダーやテックリードを自動選定。
